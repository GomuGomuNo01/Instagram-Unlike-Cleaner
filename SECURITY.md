# Politique de sécurité

## Signaler une vulnérabilité

Ne publie pas de vulnérabilité dans une *issue* publique. Utilise le signalement privé de
GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**. Une réponse est
donnée dès que possible ; ce projet est maintenu sur le temps libre de son auteur.

Sont particulièrement concernés : toute fuite d’identifiants, de cookies ou de données
personnelles, tout appel réseau vers un tiers, et tout accès à l’API locale depuis un autre
site ou un autre ordinateur.

## Garanties

Les garanties de sécurité d’IUC et les tests qui les prouvent sont décrits dans la section
[Sécurité et confidentialité](README.md#sécurité-et-confidentialité) du README.
