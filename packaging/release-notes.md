## Installer IUC sur Windows

1. Télécharge **IUC-Setup-<version>.exe** ci-dessous, puis lance-le. Aucun droit
   administrateur n’est demandé.
2. Windows peut afficher « Windows a protégé votre ordinateur » : l’installeur n’est pas
   signé (la signature de code est payante). Clique sur **Informations complémentaires**,
   puis **Exécuter quand même**.
3. Lance **IUC** depuis le menu Démarrer : l’interface s’ouvre dans ton navigateur. Garde la
   fenêtre noire ouverte pendant l’utilisation ; la fermer arrête IUC.

**Prérequis** : Google Chrome ou Microsoft Edge, que IUC pilote dans une fenêtre dédiée.

**Tes données** restent sur ton ordinateur, dans `%LOCALAPPDATA%\IUC`. La désinstallation
les conserve ; supprime-les depuis IUC (« Supprimer mes données locales »).
